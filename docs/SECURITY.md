# 数据与安全
配置原件、认证凭据、注册表数据、客户端数据库、日志和正式图纸不进入发布目录。配置模板只有占位符；本机生成文件必须留在用户自己的安装目录。

安装器不上传数据，不改注册表，不安装 AutoCAD/SketchUp，不覆盖已有 Skill 或客户端配置。依赖下载会连接 PyPI；Ringo 按官方说明获取。

权限检查读取 HKCU/HKLM 的 32/64 位兼容设置、实际进程完整性和 GetActiveObject。注册表无 RUNASADMIN 不代表进程权限一定兼容。权限未知与连接失败应单独报告。

临时绘图需显式开关，使用唯一文件名，只关闭本轮创建的图纸，恢复原活动文档，并比较其他文档的路径、保存状态与实体数。异常时不得拿下一个活动文档作为清理目标。
