# Landscape Agent Pack 提示词速查表

先打开 AutoCAD 与已配置本地 MCP 的 Agent。以下是任务模板，不保证全部检查或完整景观设计自动完成；不能验证时要求 AI 明确报告。第一次安装请看[AI安装助手](../docs/AI_INSTALL_ASSISTANT_CN.md)，日常步骤看[小白手册](../docs/BEGINNER_USAGE_CN.md)。

## 不知道怎么写提示词？复制这个

### 用途

把日常要求交给 AI，先规划再操作测试副本。

### 直接复制

```text
使用 Landscape Agent Pack 完成下面任务：
【把你的要求写在这里】
要求不完整时，可按风景园林常规设计逻辑提出合理参数并标明假设，不为小参数反复问我；涉及真实边界、正式尺寸或不能动的对象时必须核实，不猜。
先检查AutoCAD MCP连接，再规划完整设计，然后进入CAD。
不要直接修改唯一正式文件；使用测试副本和本Pack Guard，报错先核查实际实体，不能重复创建。
完成后按已支持范围自动检查、保存，只关闭本次任务文件并重开验证，不关闭其他图纸。
告诉我实际完成内容、发现的问题和未验证项目。Layout/PDF不无限调试。
```

### 用户只需修改

【把你的要求写在这里】。

## 1. 检查连接

### 用途

每天开始画图前确认工具连接。

### 直接复制

```text
使用 Landscape Agent Pack，先检查 AutoCAD MCP 是否使用 COM backend，并确认 connected=true。不要开始绘图，先报告实际连接状态；失败时保留错误原文，不重装环境。
```

### 用户只需修改

无需修改。

## 2. 新建景观总平面

### 用途

按完整要求规划并绘制测试总平面。

### 直接复制

```text
使用 Landscape Agent Pack。项目：【项目名】；场地：【尺寸和单位】；设计要求：【入口、园路、功能、植物与构筑物要求】。
先检查连接，列出整体参数、坐标计划和假设，再在新测试DWG按计划分批画。
使用已提供的图层、Block、Guard与验收规则；未提供的标准明确说明。检查实体、图层、Block、Hatch、文字、尺寸和异常坐标。
保存并只关闭本次任务图纸，重开核查关键几何，报告未验证项。第一阶段交付DWG，不为Layout/PDF无限调试。
```

### 用户只需修改

【项目名】、【尺寸和单位】、【入口、园路、功能、植物与构筑物要求】。

## 3. 修改现有DWG

### 用途

只改测试副本中指定的内容。

### 直接复制

```text
使用 Landscape Agent Pack 检查当前测试DWG。我要修改：【修改要求】；必须保留：【不能动的内容】。
先确认文件、单位、相关图层和实体，再仅修改目标对象；创建时使用本Pack Guard，错误先核查，不重复创建。
重新测量关键尺寸，检查重复对象和图层。保存前报告实际修改内容，等我确认。
```

### 用户只需修改

【修改要求】、【不能动的内容】。

## 4. CAD检查

### 用途

先只读找问题，确认后再修改。

### 直接复制

```text
使用 Landscape Agent Pack 检查当前DWG，先不要修改。
检查错误图层、重复实体、零长度实体、应闭合未闭合的边界、异常坐标、Block、Hatch、文字与尺寸，以及乔木压园路、明显越界和园路断路。
依据实际边界与设计要求判断，不确定就标记待复核。输出位置、证据、建议和未能检查的项目，等我确认后再修改。
```

### 用户只需修改

无需修改；若图层含义不清，补充设计要求。

## 5. 增加乔木

### 用途

在指定范围添加可核查的树木对象。

### 直接复制

```text
使用 Landscape Agent Pack，在当前测试DWG的【种植区域】增加乔木，要求：【树种、数量或间距及冠幅】。
先识别边界、园路与现有树木，规划位置，不猜测未知边界。可复用已确认的树木Block；没有就先说明表示方法。
使用本Pack Guard创建，报错先查句柄与几何，不重复放树。完成后核对数量、图层、明显越界与压园路问题，报告无法确认项，不改其他对象。
```

### 用户只需修改

【种植区域】、【树种、数量或间距及冠幅】。

## 6. 修改园路

### 用途

调整目标园路并保留其他设计。

### 直接复制

```text
使用 Landscape Agent Pack，只在测试副本修改【目标园路】，要求：【宽度、走向或连接要求】。
先识别相关实体并规划坐标，保留其他道路和冻结对象。先核实无法确定的连接点，不盲目Trim/Extend。
新增实体使用本Pack Guard，错误先核查。完成后测量宽度、检查断路、边界与重复线，保存前报告实际修改内容，等我确认。
```

### 用户只需修改

【目标园路】、【宽度、走向或连接要求】。

## 7. 铺装 / Hatch

### 用途

为指定边界添加或调整铺装表达。

### 直接复制

```text
使用 Landscape Agent Pack，在测试副本的【铺装区域】表达【材料或填充要求】。
先检查边界闭合、重复线和单位，再说明图案与比例。Hatch使用已支持的Guard验证范围；复杂边界未验证时先报告，不盲目重试填充。
完成后检查Hatch数量、面积、图层和目标范围，不修改冻结边界，列出待复核项。
```

### 用户只需修改

【铺装区域】、【材料或填充要求】。

## 8. 景观构筑物

### 用途

在测试总平面添加尺寸明确的构筑物表达。

### 直接复制

```text
使用 Landscape Agent Pack，在测试DWG添加【构筑物类型与位置】，尺寸要求：【长宽及需要表达的高度】。
先规划坐标、图层与Block表示方法，再按已支持能力绘制；不要把总平表达当作完整施工图。
创建使用本Pack Guard，错误先核查实际对象。检查位置、关键尺寸、Block引用和重复实体，保留其他设计，报告未验证项。
```

### 用户只需修改

【构筑物类型与位置】、【长宽及需要表达的高度】。

## 9. 尺寸标注

### 用途

为明确的对象添加可复核的尺寸。

### 直接复制

```text
使用 Landscape Agent Pack，在测试副本标注【目标对象或关键尺寸】，要求：【单位、文字高度或标注要求】。
先实际测量并确认标注位置与样式，不重复标注。仅在已验证的Guard参数范围内创建；不支持的样式或类型先报告，不绕过安全核查。
完成后核对测量值、Dimension数量、文字位置与重复对象。部分Dimension仍有兼容限制，未核查的端点或样式明确列出。
```

### 用户只需修改

【目标对象或关键尺寸】、【单位、文字高度或标注要求】。

## 10. 保存重开验证

### 用途

核对本次任务是否实际保存到 DWG。

### 直接复制

```text
使用 Landscape Agent Pack，把本次测试图纸保存到【输出文件】。
先核实授权目标文件与保存状态，记录实体数量、图层、Block引用、Hatch、Dimension及关键尺寸。
只关闭本次任务文档，不关闭其他图纸；关闭报错先查文档是否已消失，不重复关闭。重开该文件并重新测量，比较保存前后结果。
报告实际DWG路径、保存和重开状态、数量与尺寸差异、未验证项。不能安全确认目标时停止，不假报完成。
```

### 用户只需修改

【输出文件】。

## 11. CAD → SketchUp

### 用途

在两端环境已测试后尝试可选 / Experimental 建模。

### 直接复制

```text
使用 Landscape Agent Pack 的 CAD→SketchUp 工作流，处理【测试DWG与建模要求】。
本次明确要求连接已经运行的SketchUp/Ringo，先检查两端状态；任一不通过就停止。
先检查CAD单位、图层、闭合、重复线和异常Z，只在副本清理，问题先报告。真实DWG实体是XY依据，保留CAD_REFERENCE。
模型使用Group、可复用Component和Tag，不产生大面积粘连裸几何。保存测试模型后重开，核对尺寸与几何来源，报告偏差和待复核项。
```

### 用户只需修改

【测试DWG与建模要求】。

## 12. 出错诊断

### 用途

保留证据并只读判断是否是假失败。

### 直接复制

```text
使用 Landscape Agent Pack 诊断【错误原文，先去掉个人路径与认证凭据】，先不要修改或重复创建。
回读连接、当前目标文档和相关实体；核对已有创建凭据、新增句柄、实体数量及关键几何。
已确认创建成功时按Guard规则记录SUCCESS_WITH_FALSE_ERROR并阻止重复创建；不能确认就报告待复核或真实失败。
保留原始错误，给出最小下一步，不自动重装、改注册表、Fork上游或无限调试Layout/PDF。
```

### 用户只需修改

【错误原文，先去掉个人路径与认证凭据】。
