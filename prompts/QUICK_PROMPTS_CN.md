# Landscape Agent Pack 提示词速查表

安装配置完成后，直接描述想法即可，不需要记住工具名。你确认设计目标，AI规划，Agent按本Pack规则执行，AI核查真实结果，你继续反馈。完整景观绘图仍属实验阶段，模板不是能力验收承诺。

[项目工作原理](../docs/HOW_IT_WORKS_CN.md) · [小白手册](../docs/BEGINNER_USAGE_CN.md) · [首次安装助手](../docs/AI_INSTALL_ASSISTANT_CN.md)

## 最推荐：直接告诉AI你的想法

### 用途

把设计意图交给AI，确认方案后由Agent执行。

### 直接复制

```text
使用 Landscape Agent Pack 完成下面的景观设计任务。
项目：【项目是什么，例如校园口袋公园】
场地：【场地是什么，例如30m×20m】
我的想法：【直接用自己的话描述】
必须保留：【不能动的内容，没有写无】
最终需要：【文件类型和输出位置，例如景观总平面DWG】
次要参数请根据风景园林常规设计逻辑合理补充并标明假设，不为每个小尺寸反复问我。真实边界、正式尺寸、冻结对象及矛盾要求必须核实，不猜测。
先完成整体设计规划，等我确认主要方案后，通过Agent和已配置的工具在新文件或副本执行。
按本Pack工作流检查实际结果并保存重开验证，只操作本次任务文件。最后告诉我设计思路、实际完成内容、关键参数、文件位置、检查结果和仍存在的问题。
```

### 用户只需修改

项目、场地、想法、保留内容和最终文件。

## 1. 检查连接

### 用途

每天开始前确认本机工具可用。

### 直接复制

```text
使用 Landscape Agent Pack，先检查AutoCAD连接和工具是否可用，不绘图。报告实际状态与问题，不重装环境。
```

### 用户只需修改

无需修改。

## 2. 新建景观总平面

### 用途

先讨论完整方案，再绘制测试总平。

### 直接复制

```text
使用 Landscape Agent Pack 完成任务。项目：【项目名】；场地：【尺寸和单位】；我的想法：【设计要求】；必须保留：【不能动的内容】；最终需要：【DWG与输出位置】。先规划并标明假设，等我确认主要方案后执行，按本Pack规则检查与交付。
```

### 用户只需修改

项目、场地、想法、保留内容和最终文件。

## 3. 修改现有DWG

### 用途

只调整测试副本中的目标内容。

### 直接复制

```text
使用 Landscape Agent Pack，修改当前测试DWG。我要修改：【修改要求】；必须保留：【不能动的内容】。先说明计划，只改相关对象，核查实际结果，保存前报告修改内容，等我确认。
```

### 用户只需修改

【修改要求】、【不能动的内容】。

## 4. CAD检查

### 用途

先检查和给建议，不直接修改。

### 直接复制

```text
使用 Landscape Agent Pack，只读检查当前DWG。重点：【想检查的问题，例如道路断路、树木越界、尺寸或重复对象】。依据实际图纸报告位置、证据、建议和未验证项，等我确认再修改。
```

### 用户只需修改

【想检查的问题】。

## 5. 增加乔木

### 用途

根据种植想法规划位置并核查结果。

### 直接复制

```text
使用 Landscape Agent Pack，在测试图的【种植区域】增加乔木，要求：【树种、数量或间距及冠幅】。保留现有设计，先规划位置，确认主要方案后执行，检查数量、越界与压园路问题，报告无法确认项。
```

### 用户只需修改

【种植区域】、【树种、数量或间距及冠幅】。

## 6. 修改园路

### 用途

在不改变保留内容的前提下调整道路。

### 直接复制

```text
使用 Landscape Agent Pack，调整测试图的【目标园路】，要求：【宽度、走向或连接要求】；不能动：【保留内容】。先说明计划与影响，确认后执行并检查关键尺寸、连续性及实际结果。
```

### 用户只需修改

【目标园路】、【宽度、走向或连接要求】、【保留内容】。

## 7. 铺装 / Hatch

### 用途

表达指定区域的铺装材料。

### 直接复制

```text
使用 Landscape Agent Pack，为测试图的【铺装区域】表达【材料或填充要求】。不要改冻结边界，先说明计划，检查边界与实际结果。不支持或不能验证的表达明确报告，不盲目重复操作。
```

### 用户只需修改

【铺装区域】、【材料或填充要求】。

## 8. 景观构筑物

### 用途

绘制尺寸明确的构筑物总平表达。

### 直接复制

```text
使用 Landscape Agent Pack，在测试图添加【构筑物类型与位置】，尺寸：【长宽及需要表达的高度】。保留其他设计，先规划再执行，核查位置与尺寸。最终需要总平表达，不能当作完整施工图，列出未验证项。
```

### 用户只需修改

【构筑物类型与位置】、【长宽及需要表达的高度】。

## 9. 尺寸标注

### 用途

为目标对象添加能复核的尺寸表达。

### 直接复制

```text
使用 Landscape Agent Pack，为测试图的【目标对象】添加尺寸，表达要求：【单位、文字大小等】。先实际测量，检查是否已有标注，再按已支持范围执行并核查结果，明确报告未验证的样式或端点。
```

### 用户只需修改

【目标对象】、【表达要求】。

## 10. 保存重开验证

### 用途

确认本次任务文件已实际保存。

### 直接复制

```text
使用 Landscape Agent Pack，将本次测试图纸保存到【输出文件】，按工作流关闭本次任务文档并重开核查，不能关闭其他图纸。报告文件位置、关键尺寸、实际检查结果、差异与未验证项。无法安全确认目标就停止。
```

### 用户只需修改

【输出文件】。

## 11. CAD → SketchUp

### 用途

两端环境通过后尝试可选实验建模。

### 直接复制

```text
使用 Landscape Agent Pack，把【测试DWG与建模要求】转为SketchUp基础模型。本次明确要求连接已经运行的SketchUp，先检查环境，未通过就停止。保留原CAD与正式模型，依据真实DWG建模并清楚分组，避免粘连，保存重开核对尺寸，报告偏差与未验证项。
```

### 用户只需修改

【测试DWG与建模要求】。

## 12. 出错诊断

### 用途

保留证据，先判断实际状态再处理。

### 直接复制

```text
使用 Landscape Agent Pack，诊断【去掉个人路径与认证凭据后的错误原文】。先只读检查实际文件与对象，不修改或重复创建。报告已发生的操作、实际状态、原因和最小下一步，不自动重装、修改系统设置或无限调试自动出图。
```

### 用户只需修改

【已清理的错误原文】。

## 执行规则由谁负责？

用户模板不必反复列技术操作。执行Agent需要先读取本Pack的[安全规则](../standards/autocad-safety-rules.md)、[Guard规则](../guards/README.md)和[当前限制](../docs/LIMITATIONS.md)，在授权副本上组织图层与Block、核查实际创建结果、保存重开验收。规则不是自动生效的工具拦截层；创建失败时禁止盲目重复，不能验证的项目须明确列出。

SketchUp为可选 / Experimental，当前RC未完成运行时测试；没有明确请求时不启动或连接。优先交付正确的模型空间DWG，Layout / PDF Beta不扩展为无限调试。
